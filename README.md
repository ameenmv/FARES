# Fares Mohammed — Portfolio

Personal portfolio for Fares Mohammed, a senior graphic designer specializing in brand identity, packaging, and campaign design across Egypt and Saudi Arabia.

---

## Tech Stack

- **Framework:** Nuxt 3
- **Styling:** Tailwind CSS v4
- **Animations:** GSAP + ScrollTrigger
- **Smooth Scroll:** Lenis
- **Fonts:** Outfit, Inter (Google Fonts)

## Getting Started

```bash
# Install dependencies
bun install

# Start dev server
bun dev

# Build for production
bun run build
```

## Project Structure

```
pages/
  index.vue          # Home
  about.vue          # About
  contact.vue        # Contact
  work/
    index.vue        # Work archive
    [slug].vue       # Case study detail

components/
  home/              # Home page sections
  layout/            # Header, Footer, Cursor
  work/              # Work page components

assets/css/
  main.css           # Design system and base styles
```

## Design

- Light premium theme with a monochrome palette
- Scroll-driven animations and page transitions
- Responsive across all breakpoints
- Custom cursor and smooth scrolling
